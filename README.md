# 锐评 · 音乐评分墙

把一张歌单铺成一面可拖动的评分墙：**导入 → 配封面 → 拖封面打分 → 写锐评 → 出整体报告**。

纯静态站点，零后端、零构建。所有数据保存在你自己的浏览器里，不上传任何服务器。

## 怎么用

1. **导入歌单** — 点右上角「管理」，三种方式任选：
   - 从网易云歌单页全选复制，粘进文本框（最稳，不依赖网络）
   - 粘贴 `music.163.com/playlist?id=…` 链接自动抓取
   - 上传 `.txt` / `.csv` / `.m3u` / 之前的 JSON 存档
2. **配封面** — 导入后自动匹配专辑封面；匹配不准可在卡片上点「⇄」手动更换
3. **打分** — 拖动封面到评分轨道上，10 档（0.5–5），松手即存
4. **写锐评** — 卡片里点「编辑」，写一段短评、贴几个标签
5. **看整体结果** — 右侧总榜底部「结束锐评 · 看整体结果」，生成综合评级、等级分布、高分/低分 Top3 与口味画像

## 功能

- **拖动评分**：位置即分数，等级 S/A/B/C/D 实时映射
- **背景自定义**：8 个预设 + 上传图片 / 纯色 / 渐变，可调透明度、亮度、模糊、饱和度；偏好本地保存，刷新自动恢复
- **锐评报告**：自动汇总平均分、等级分布、封神与劝退曲目、标签频次
- **导出**：JSON 存档（可回导续用）与 CSV

## 数据与隐私

- 所有歌单、评分、锐评、外观偏好都存在浏览器 `localStorage`（键名 `mrd_state_v1` / `mrd_bg_v1` 等）
- **没有任何后端，不上传数据**
- 清理浏览器数据会**丢失全部记录** —— 建议定期用「导出存档 JSON」备份

## 本地运行

直接双击 `index.html` 也能用，但有两项会降级：

| 能力 | http 环境 | `file://` 直接打开 |
|---|---|---|
| 动态金色海面 | ✓ | ✗（降级为静态背景） |
| 自动匹配封面 | ✓ | ✗（跨域被拦，页面会提示） |

需要完整体验时起一个本地静态服务即可：

```bash
npx serve .
# 或
python -m http.server 8000
```

## 已知限制

- **网易云链接抓取依赖公共镜像**，镜像故障时该通道会失败；「文本粘贴」通道不受影响
- 动态背景需要读取同目录的 `bg-sea-gold-*.jpg`，单独分享 HTML 文件时请一并带上
- 仅支持现代浏览器（用到 `oklch()`、CSS 变量、Pointer Events）

## 技术栈

单个 HTML 文件（HTML + CSS + JS 全内联），无框架、无构建步骤、无运行时依赖。
动态海面为 WebGL1 手写 shader（12 秒无缝循环），失败时自动降级为静态背景图。
